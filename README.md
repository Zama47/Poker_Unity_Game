# Poker_Unity_Game

Карточный покер на Unity, где вы сражаетесь один на один с ботом. Реализованы все основные комбинации и упрощённая логика ставок.

## Стек технологий
- **Unity** 6000 
- **C#** .NET Standard 2.1
- Платформа: ПК (Windows)

## Основные механики
- Колода из 52 карт, случайное перемешивание
- Раздача по 2 карманные карты игроку и боту, 5 общих карт на столе
- Определение выигрышной комбинации: от старшей карты до флеш-рояля
- Простой ИИ бота: чекает / коллирует / повышает ставку на основе силы карт
- Отображение текущего банка и результата раунда

## Как запустить (для рекрутера)
1. Установите Unity Hub и Unity версии 2022.3 LTS (или новее)
2. Скачайте репозиторий:  
   `git clone https://github.com/Zama-47/Poker.git`
3. Откройте папку проекта в Unity Hub (Add → выберите папку)
4. Нажмите кнопку **Play** в Unity
